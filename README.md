# MASAR — Forsa Opportunity Finder

A bilingual opportunity finder for students and early-career explorers in Egypt. Built with Node.js and browser-native HTML, CSS, and JavaScript. There is no database, account system, or third-party package dependency.

## Run locally

```sh
npm start
```

Then open [http://localhost:3000](http://localhost:3000).

## Customize

- Update the sample opportunities in `public/app.js` with your own listings and organizer links.
- Add an owner email to `CONTACT_EMAIL` near the top of `public/app.js` when you are ready to receive hosting requests. The contact form opens a prefilled email draft; it does not submit to a server.
- The language, theme, and saved opportunities are stored in the visitor's browser using local storage.

The built-in listings are clearly marked as sample previews. Always replace them with confirmed details before publishing the directory.
